# Education Made EZ

Adaptive learning that marks like the examiner, finds what each student is missing, and decides what they
practise next. One engine, many curricula.

- **magister** — the first product: Cambridge O Level and A Level, every paper since 2020, marked against the real mark scheme.
- **company** — the website, the handbook (plans, pricing, decisions) and infrastructure notes.
- **media** — the launch films and teasers.

Building in stealth from Karachi.
